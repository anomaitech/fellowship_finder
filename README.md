# Fellowship Finder

Complete directory of 350+ Plastic & Reconstructive Surgery fellowship programs across the USA.

## Features
- **350+ programs** across 11 subspecialties (microsurgery, hand, craniofacial, burn, aesthetic, research, gender affirming, peripheral nerve, facial plastic, wound care, and more)
- **Academic centers + private practices** included
- Verified contacts from actual hospital websites
- IMG (International Medical Graduate) eligibility and visa sponsorship info
- Search and filter by program type, IMG-friendliness
- Action timeline and application strategy
- Email templates and networking tips
